⌨️ Atalhos e dicas

Atalhos de teclado

  • Ctrl + S → Salvar paciente no banco
  • Ctrl + P → Imprimir / gerar PDF
  • Ctrl + L → Abrir banco de pacientes
  • Ctrl + N → Novo laudo

Dicas para impressão

  • Use Chrome ou Edge para a melhor qualidade de PDF
  • Em "Imprimir", marque "Gráficos de plano de fundo" para a folha timbrada aparecer no PDF
  • Margens: Padrão ou Nenhuma
  • Escala: Padrão (100%)

Banco de pacientes

  • Dados salvos apenas no seu navegador (não saem do computador)
  • Faça backup semanal via "Exportar JSON"

💾 Salvamento automático em pasta

  1. Configuração única: Clique em "📁 Pasta destino" e escolha a pasta onde quer salvar todos os laudos (ex: "Laudos ECG" no Documentos)
  2. A pasta fica memorizada — você só precisa fazer isso UMA vez
  3. Para cada laudo: clique em "💾 Salvar PDF" ou "🔏 Salvar PDF p/ VIDaaS"
  4. O arquivo é salvo automaticamente na pasta com o nome: NOME DO PACIENTE.pdf
  5. Proteção contra sobrescrita: se já existir um laudo com o mesmo nome (paciente de retorno), a data do exame é adicionada automaticamente — ex: MARIA DA SILVA 2026-05-25.pdf. Nenhum laudo anterior é perdido.
  6. Para trocar a pasta, clique novamente em "📁 Pasta destino"
  7. Para escolher pasta diferente em um laudo específico, use "🖨️ Imprimir" (Ctrl+P) e salve manualmente

⚠ Esta funcionalidade requer Chrome, Edge ou Brave. No Firefox/Safari, use "🖨️ Imprimir" para salvamento tradicional.

🔏 Assinatura digital VIDaaS

  1. Configuração única: Ative seu certificado VIDaaS-CFM (gratuito para médicos) em vidaas.com.br + instale o app no celular + o VIDaaS Connect no PC
  2. Carregue sua assinatura: Clique em "Carregar assinatura" e selecione uma foto/scan da sua rubrica (fica salva no navegador)
  3. Para cada laudo: Clique em "PDF para VIDaaS" em vez de "PDF simples"
  4. O PDF será gerado com um espaço reservado no rodapé direito
  5. Abra o PDF no VIDaaS Connect (desktop) → arraste o carimbo de assinatura para dentro do espaço reservado
  6. Aprove no app do celular (biometria) → PDF assinado digitalmente, pronto para entregar ao paciente
  7. Validade jurídica: assinatura ICP-Brasil qualificada (Lei 14.063/2020) — equivalente legal ao papel assinado

A assinatura escaneada (imagem) é apenas visual. A validade jurídica vem do carimbo criptográfico do VIDaaS.
